# WEB BASE V3

## Web base v3 based on:

- React 17, umijs, antd v4
- TypeScript
- SSO with Keycloak
- Back-end: NestJS, PostgreSQL

This project is initialized with [Web Base](https://pro.ant.design). Follow is the quick guide for how to use.

## Environment Prepare

Install `node_modules`:

```bash
yarn
```


### Start project

```bash
yarn start
```

### Build project

```bash
yarn build
```
